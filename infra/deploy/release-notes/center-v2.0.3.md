## 修复与改进

- 💳 环境未设置支付密码时，阻止开启自动转账。历史无密码环境也不会生成或领取自动转账任务。
- 🔒 脚本设置新增「账号受限时自动关闭关联通道」。开启后处理已有受限账号，后续巡检发现商家资金限制或司法限制时自动关停关联通道。
- 🔓 脚本设置新增「账号解除限制时自动恢复通道」。两类限制均已解除后，恢复系统因受限关闭且没有其他停用原因的通道。
- 🖼️ Telegram 受限和恢复通知附带卡片，按站点列出实际关闭或开启的通道及失败原因。受限通知附上本轮已取得的巡检截图。
- 🔔 Telegram 通知路由新增「账号解除限制」，支持独立选择接收群和测试发送。自动恢复关闭时仍可收到账号恢复通知。
- ⚙️ Telegram 通知路由新增「站点策略触发」。规则生成正式调整记录后，通知包含命中规则、目标、计划动作和调整记录编号。
